# HR Analytics Tableau Dashboard

This dashboard provides insights on employee attrition, age distribution, department-wise overview, job satisfaction ratings, and gender-based attrition patterns.

It includes:

- Employee count & active employees
- Attrition rate and attrition by department
- Age distribution histogram
- Job satisfaction heatmap
- Attrition by education field
- Attrition rate by age groups and gender
